## Пацаноидное равновесие

| Событие | Название | Категория |
| :------ | ---- | ---- |
| StudentCTF 2026 | Пацаноидное равновесие | reverse |

### Описание

>Два пацаноида просто не могут жить друг без друга. В чем же заключается их связь?

### Решение

Два пацаноида это драйвер и приложение-клиент взаимодействующее с ним. Анализ дает понять, что клиент принимает ввод пользователя, прогоняет через несколько раундов Сети Фейстеля, передает промежуточный результат драйверу, тот прогоняет до конца и сверяет с эталоном, после чего отправляет клиенту сигнал о валидности ввода.

Скрипт для получения флага представлен в файле [solve.py](solve.py).

### Флаг

```
stctf{0dfdceacbdc88885ac4fdaf40}
```
