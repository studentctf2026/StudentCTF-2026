## Broken Malware

| Событие | Название | Категория |
| :------ | ---- | ---- |
| StudentCTF 2026 | Broken Malware | reverse |

### Описание

>В эру вайбкодинга даже вирусы работают не так как задумано.

### Решение

Игроку дается архив с ярлыком. Посмотрев свойства ярлыка можно увидеть что при его открытии запускается PS скрипт извлекающий полезную нагрузку из архива (как последовательность байт самого файла).

Извлекаем пейлод сами [extract.py](extract.py). Он представляет собой .exe файл. Проводим его реверс-инжениринг.

Функционал пейлода:

1) Подключение к серверу — получает флаг по TCP с сервера

2) Выбор случайной папки среди Temp, Documents, AppData, Public

3) Генерация случайного имени для файла (8-14 символов + расширение .dat/.tmp/.log/.cfg/.ini)

4) Создание основного файла с мусорным содержимым и установка атрибута Скрытый

5) Сохранение флага в альтернативный поток данных (ADS)

6) Создание файлов-пустышек (2-5 шт.) в той же папке для маскировки

7) Создание фальшивых ADS (1-3 шт.) для отвлечения внимания

Перехватить флаг можно либо через WireShark либо посмотреть куда флаг сохраняется в настоящий момент под отладкой.
Флаг закодирован в Base64. При раскодировании все равно не получаем флаг. В бинарнике есть жирный намек на алгоритм шифрования - неиспользуемые функции RC4. Но раз так, то должен быть ключ. Его передает сервер. Пейлод его не принимает, но в трафике он виден. Расшифровываем флаг с помощью ключа. [decrypt_flag.py](decrypt_flag.py) Таск решен.
