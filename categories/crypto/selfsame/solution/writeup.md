## SELFSAME
| Событие | Название | Категория |
| :------ | ---- | ---- |
| StudentCTF | SELFSAME| crypto |

  
### Описание


>Мы перехватили реализацию блочного шифра, очень похожего на ГОСТ 28147-89 (или его упрощённую версию). Шифр работает с 64-битными блоками, использует 32-битную функцию раунда F, S-box'ы и линейное преобразование MC. Ключ, разумеется, секретный.

### Решение
Назовём `(P, P')` **скользящей парой**, когда `P' = Round(P)`. При
`P=(L,R)`, `P'=(L',R')` и шифртекстах `C=(Lc,Rc)`, `C'=(Lc',Rc')`:

```
сторона открытого текста :  L' = R          R' = L  XOR F(R)
сторона шифртекста       :  Lc' = Rc        Rc' = Lc XOR F(Rc)
```

Итак, одна скользящая пара даёт **две** пары вход/выход функции `F`:

```
F(R)  = R' XOR L        (из открытых текстов)
F(Rc) = Rc' XOR Lc      (из шифртекстов)
```


иксируем 32-битную константу `a` и строим две структуры по `2^18` блоков
каждая:

```
A = { (x_i, a) }        левая половина меняется, правая = a
B = { (a, y_j) }        левая половина = a,       правая меняется
```

Любая пара `(P из A, P' из B)` уже удовлетворяет `L' = R` (обе равны
`a`). Она является настоящей скользящей парой тогда и только тогда, когда
дополнительно `y_j = x_i XOR F(a)`. Значение `F(a)` нам неизвестно,
поэтому фильтруем по условию на шифртекст `Lc' = Rc` — 32-битное
совпадение, находится через хеш-таблицу по левым половинам шифртекстов
структуры `B`.

Подсчёт: `2^18 · 2^18 = 2^36` пар-кандидатов, каждая проходит 32-битный
фильтр с вероятностью `2^-32`, то есть ≈ `2^4 = 16` выживших. Настоящие
скользящие пары (их около 16, по одной на `x_i`, так как у каждого
уникальный партнёр) все лежат внутри этого множества; горстка случайных
коллизий бесплатно отсеивается на этапе восстановления ключа.



`F(u) = Kb XOR MC(SB(u XOR Ka))`. Имея два сэмпла `(u1,v1)`, `(u2,v2)`:

```
MC^{-1}(v1 XOR v2) = SB(u1 XOR Ka) XOR SB(u2 XOR Ka)
```

`Kb` сократился. Уравнение побайтовое: для каждого из четырёх байтов пара
`(входная разность, выходная разность)` выбирает возможные входы S-box из
таблицы распределения разностей (DDT), значит даёт несколько кандидатов
для этого байта `Ka`. Произведение по четырём байтам ≈ несколько сотен
кандидатов `Ka`; каждый фиксирует `Kb = v1 XOR MC(SB(u1 XOR Ka))`.
Проверяем на известной паре открытый текст/шифртекст (любой блок из
структуры `A`).

Пары-импостеры из фильтра по шифртексту либо не дают решения по DDT, либо
дают ключ, не прошедший проверку, — так что они ничего не стоят.
